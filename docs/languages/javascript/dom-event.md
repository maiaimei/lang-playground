DOM事件核心知识点笔记
一、什么是DOM事件

DOM事件是前端实现交互的核心机制，它是用户操作或浏览器行为触发的特定动作，比如点击按钮、键盘输入、页面滚动等。通过监听这些事件并绑定处理函数，就能让静态页面动态响应用户操作，实现丰富的交互效果。

二、事件三要素
事件源‌：触发事件的DOM元素，也就是事件发生的目标位置，比如被点击的按钮、输入文字的输入框，可通过event.target获取原始事件源。
事件类型‌：定义了触发事件的交互类型，常见的有鼠标事件click、键盘事件keydown、表单事件submit、窗口事件scroll等。
事件处理程序‌：事件触发后自动执行的回调函数，函数接收一个事件对象event作为参数，内部可以编写任意交互逻辑，比如修改页面样式、提交表单数据等。
三、事件注册/绑定的三种方式
表格
绑定方式	实现方式	优缺点
HTML内联属性	直接在标签上写onclick="handleClick()"	简单直观，但HTML和JS强耦合，只能绑定一个处理函数，现代开发不推荐使用
DOM0级属性绑定	通过JS给元素的事件属性赋值：btn.onclick = function(){}	实现了结构和行为分离，但同一事件只能绑定一个处理函数，后面的赋值会覆盖前面的
DOM2级addEventListener（推荐）	使用btn.addEventListener('click', handler, false)绑定	支持同一事件绑定多个处理函数，可控制在捕获/冒泡阶段触发，支持精确移除事件，是目前标准的事件绑定方式
四、事件移除
DOM0级绑定的事件：直接将事件属性设为null即可移除，比如btn.onclick = null。
DOM2级绑定的事件：必须使用removeEventListener，且传入的事件类型、处理函数引用、第三个参数必须和绑定时完全一致，匿名函数无法被正确移除。
五、事件流的三个阶段
捕获阶段‌：事件从window对象自上而下向目标元素传播，路径为window → document → html → body → ... → 目标父元素。
目标阶段‌：事件到达触发它的原始目标元素，此时事件在目标元素上执行处理逻辑。
冒泡阶段‌：事件从目标元素自下而上反向传播回window，是事件委托机制的核心原理。
六、事件对象常用API

事件处理函数接收的event对象包含事件的全部信息，常用属性和方法：

event.target：触发事件的原始元素
event.currentTarget：当前正在处理事件的绑定元素
event.preventDefault()：阻止浏览器的默认行为，比如阻止链接跳转、表单自动提交
event.stopPropagation()：阻止事件继续向上冒泡或向下捕获
七、事件委托

利用事件冒泡机制，将多个子元素的事件统一绑定到父元素上，通过判断event.target的标签名或属性来执行对应逻辑。这种方式无需为动态新增的子元素重复绑定事件，大幅减少内存占用，是处理动态列表事件的最佳实践。
